# 曲库

把音频文件直接放进这个目录即可，**文件名（不含扩展名）就是歌名**。

```
songs/
  茉莉花.mp3
  军港之夜.mp3
```

支持 `.mp3 .wav .flac .ogg .m4a .aac`（由 libsndfile 解码）。

## 自动生效范围

歌名会自动成为【可用指令集】里"播放歌曲"的可选值 —— LLM 提示词和指令校验
都会跟着变，**不需要改任何代码**。

- 曲库为空时，"播放歌曲"这条指令根本不会注册，机器人不会承诺唱它没有的歌
- 新增歌曲后需**重启 brain_node**（指令集在模块导入时构建）

## 播放行为

- 单曲上限 60 秒（`config.SONG_MAX_SEC`），超时自动淡出，不做打断
- 播放期间麦克风处于静音态，不会把歌声当成用户指令收回来
- 播放在 TTS 说完之后开始，不会与语音抢扬声器

## 关于音源

音频文件请自行确认授权。注意**词曲版权与录音版权是两回事** ——
《茉莉花》曲调是公版，但某个歌手 2010 年的录音仍受版权保护。
